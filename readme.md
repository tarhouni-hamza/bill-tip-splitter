# 💸 Bill & Tip Splitter

A lightweight Python command-line utility for calculating tip amounts, total bills, and splitting costs among a group of people.

---

## 🚀 Features

- **Custom Bill & Tip Input:** Supports custom total bill amounts and percentage-based tips.
- **Group Cost Splitting:** Divides total bills evenly across any number of people.
- **Interactive Session Loop:** Perform multiple calculations in one run.
- **Clean Formatting:** Displays currency output formatted to two decimal places.

---
